# Everon

[![Build](https://github.com/StanleyLl0yd/everon/actions/workflows/build.yml/badge.svg)](https://github.com/StanleyLl0yd/everon/actions/workflows/build.yml)

[English](README.md) | [Русский](README.ru.md)

Everon — лёгкая нативная утилита для Windows, работающая из системного трея и не дающая компьютеру автоматически уходить в сон, когда это необходимо. Приложение работает в фоне и не требует отдельного главного окна.

## Возможности

- Предотвращение автоматического сна системы
- Опциональное удержание дисплея включённым
- Опциональная периодическая отправка F15/F16/F17
- Режимы таймера:
  - Бесконечно
  - На выбранную длительность
  - До указанного времени суток
- Включение и отключение из меню в трее
- Глобальная горячая клавиша для быстрого переключения
- Опциональный запуск вместе с Windows
- Уведомления о важных событиях
- Шесть языков интерфейса: английский, русский, французский, немецкий, итальянский и испанский
- Защита от запуска нескольких экземпляров: повторный запуск открывает настройки уже работающего Everon
- Автоматическое восстановление иконки после перезапуска Windows Explorer

## Для каких задач подходит

- Длительные загрузки и выгрузки
- Презентации и встречи
- Мониторинг и автоматизация
- Воспроизведение медиа
- Поддержание рабочего ПК активным во время коротких перерывов

## Требования

- Windows 10 или Windows 11
- Публикуемая сборка — x64
- Права администратора не требуются

Everon является portable-приложением: установщик не нужен, а настройки сохраняются для текущего пользователя в реестре Windows по адресу `HKCU\Software\Everon`.

## Быстрый старт

1. Скачайте `Everon.exe` из последнего GitHub Release.
2. Запустите файл.
3. Найдите иконку Everon в системном трее Windows.
4. Нажмите на неё правой кнопкой мыши, чтобы включить/отключить Everon или открыть **Настройки**.
5. При необходимости настройте таймер, удержание дисплея, отправку клавиши, горячую клавишу, уведомления, язык и автозапуск Windows.

Если включён **Запуск с Windows**, храните `Everon.exe` в постоянном месте. После перемещения файла путь изменится, поэтому автозапуск следует заново включить в настройках.

## Как это работает

Everon использует стандартный Windows API `SetThreadExecutionState`, чтобы сообщить системе о необходимости сохранять активное состояние. При включённой опции **Не выключать экран** дополнительно запрашивается сохранение активности дисплея. Опциональная отправка F15/F16/F17 выполняется через `SendInput` и по умолчанию отключена.

Активный таймер сохраняет конечный момент как абсолютное время UTC, что делает режимы длительности и «до времени» устойчивее к перезапускам приложения и типовым ситуациям с переводом часов/DST.

## Сборка из исходников

### Необходимо

- Visual Studio 2022 или Visual Studio Build Tools 2022
- Компонент **Desktop development with C++**
- CMake 3.21 или новее

### Настройка, сборка и тестирование

```powershell
cmake -S . -B build -A x64 -DBUILD_TESTING=ON
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
```

Готовый EXE обычно находится здесь:

```text
build\Release\Everon.exe
```

В репозитории также есть GitHub Actions workflow, который выполняет аналогичную x64 Release-сборку и запускает тесты на `windows-latest`.
