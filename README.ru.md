# Everon

[![Build](https://github.com/StanleyLl0yd/everon/actions/workflows/build.yml/badge.svg)](https://github.com/StanleyLl0yd/everon/actions/workflows/build.yml)

[English](README.md) | [Русский](README.ru.md)

Everon — небольшая нативная утилита для Windows, работающая из системного трея и предотвращающая автоматический переход системы в сон, пока приложение включено. Отдельного главного окна у программы нет.

## Возможности

- Предотвращает автоматический сон системы через Windows API `SetThreadExecutionState`
- При необходимости может дополнительно удерживать дисплей активным
- Может опционально отправлять F15, F16 или F17 через `SendInput` с интервалом от 1 секунды до 24 часов
- Режимы таймера:
  - Бесконечно
  - На выбранную длительность
  - До ближайшего наступления выбранного локального времени
- Включение и отключение Everon из меню в трее
- Двойной щелчок по иконке открывает настройки
- Опциональная настраиваемая глобальная горячая клавиша для включения/отключения Everon
- Опциональный автозапуск вместе с Windows для текущего пользователя
- Опциональные уведомления при включении и отключении Everon; завершение таймера и соответствующие ошибки также выводятся через уведомления
- Шесть языков интерфейса: английский, русский, французский, немецкий, итальянский и испанский
- Работа в одном экземпляре: повторный запуск открывает настройки уже работающего Everon
- Восстановление иконки в трее после перезапуска Windows Explorer
- Сохранение настроек текущего пользователя в `HKCU\Software\Everon`

Everon предназначен именно для предотвращения автоматического сна. Он не перехватывает команды ручной блокировки, сна, выхода из системы или завершения работы и не предназначен для обхода системных или корпоративных политик.

## Использование

1. Скачайте `Everon.exe` из последнего GitHub Release.
2. Запустите его.
3. Используйте иконку Everon в системном трее Windows:
   - Правый клик — включение/отключение Everon, **Настройки**, **О программе** и выход.
   - Двойной клик — открытие **Настроек**.
4. При необходимости настройте поведение дисплея, отправку клавиш, таймер, горячую клавишу, уведомления, язык и автозапуск.

Если включён **Запуск с Windows**, храните `Everon.exe` в постоянном месте. После перемещения файла включите автозапуск заново, чтобы обновить сохранённый путь.

## Распространение

- Portable-приложение; установщик не требуется
- Публикуемая на GitHub сборка: Windows x64
- Права администратора не требуются

## Сборка из исходников

### Необходимо

- Visual Studio или Visual Studio Build Tools с компонентом **Desktop development with C++**
- CMake 3.21 или новее

Everon собирается как Win32-приложение на C++17.

```powershell
cmake -S . -B build -A x64 -DBUILD_TESTING=ON
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
```

Готовый файл обычно создаётся здесь:

```text
build\Release\Everon.exe
```

Текущий набор тестов проверяет поведение таймера, а также разбор и сериализацию горячих клавиш. GitHub Actions выполняет x64 Release-сборку и запускает тесты в Windows.
