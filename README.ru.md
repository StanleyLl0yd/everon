Everon — лёгкая нативная утилита для Windows, работающая из системного трея и предотвращающая автоматический переход системы в сон, пока приложение включено. Отдельного главного окна у программы нет.

**Версия исходного кода:** 2.8.0 · **Платформа:** Windows x64 · **Язык:** C++17

[GitHub Releases](https://github.com/StanleyLl0yd/everon/releases)

## Возможности

- Предотвращает автоматический сон системы через Windows API `SetThreadExecutionState`.
- При необходимости может дополнительно удерживать дисплей активным.
- Настройки питания позволяют учитывать режим экономии заряда Windows и отдельно отключать удержание дисплея включённым при работе от батареи.
- Может опционально отправлять F15, F16 или F17 через `SendInput` с интервалом от **1 секунды до 24 часов**.
- Три режима таймера: **Бесконечно**, **На выбранную длительность** и **До указанного времени**.
- Быстрые таймеры из меню в трее на **15 минут**, **30 минут**, **1 час** и **2 часа**, а также отдельные нативные диалоги **Другое...** и **До времени...**.
- Выбор быстрого таймера сразу включает Everon и заменяет текущий режим таймера.
- В режиме **До указанного времени** явно показывается **Завтра**, если выбранное время уже прошло сегодня.
- Таймер длительности использует монотонные часы, пока Everon работает, поэтому изменение системного времени Windows не меняет активную длительность; после перезапуска таймер восстанавливается по сохранённому UTC-дедлайну.
- Статус в трее обновляется автоматически, поэтому оставшееся время активного таймера не устаревает.
- В меню трея показывается текущее состояние Everon и отмечается активный быстрый таймер по длительности.
- После выхода из сна или смены источника питания Everon немедленно перепроверяет таймер и запрошенный режим питания.
- Включение и отключение Everon из меню в трее.
- Один щелчок по иконке открывает **Настройки**.
- При отключённом Everon иконка в трее отображается визуально приглушённой.
- Опциональная настраиваемая глобальная горячая клавиша для включения или отключения Everon.
- Опциональный автозапуск вместе с Windows для текущего пользователя.
- Опциональные уведомления при включении и отключении Everon; завершение таймера и соответствующие ошибки также выводятся через уведомления.
- Если Windows временно не принимает запрошенный режим питания через `SetThreadExecutionState`, Everon сообщает об этом один раз и автоматически повторяет попытки.
- Шесть языков интерфейса: английский, русский, французский, немецкий, итальянский и испанский.
- Работа в одном экземпляре: повторный запуск открывает **Настройки** уже работающего Everon.
- Восстановление иконки в трее после перезапуска Windows Explorer.
- Сохранение настроек текущего пользователя в `HKCU\Software\Everon`.
- Окно **«О программе»** с установленной версией, назначением приложения, автором, лицензией и кликабельной ссылкой на репозиторий GitHub.

## Поведение системы

Everon предназначен для предотвращения автоматического сна. Пока приложение включено, оно препятствует автоматическому переходу системы в сон, но **не** перехватывает команды ручной блокировки, сна, выхода из системы или завершения работы и не предназначено для обхода системных или корпоративных политик.

Если включена настройка **Учитывать экономию заряда**, то при активации Battery Saver в Windows Everon временно снимает запрос на удержание системы активной и прекращает синтетическую отправку F15/F16/F17 до выхода из режима экономии заряда. Для существующих установок прежнее поведение сохраняется, пока эта настройка не включена пользователем.

Приложение portable, не требует установщика и прав администратора. Если включён **Запуск с Windows**, храните `Everon.exe` в постоянном месте; после перемещения файла включите автозапуск заново, чтобы обновить сохранённый путь.

## Использование

1. Скачайте `Everon.exe` из последнего [GitHub Release](https://github.com/StanleyLl0yd/everon/releases).
2. Запустите его.
3. Используйте иконку Everon в системном трее Windows:
   - правый клик — живой статус, включение или отключение Everon, запуск предустановленного/произвольного таймера или режима «До времени», **Настройки**, **О программе** и выход;
   - один клик — открытие **Настроек**.
4. При необходимости настройте поведение дисплея и батареи, отправку клавиш, таймер, горячую клавишу, уведомления, язык и автозапуск.

## Сборка из исходного кода

Требуются Visual Studio или Visual Studio Build Tools с компонентом **Desktop development with C++**, а также CMake 3.21 или новее.

```powershell
cmake -S . -B build -A x64 -DBUILD_TESTING=ON
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
```

Готовый файл обычно создаётся здесь:

```text
build\Release\Everon.exe
```

Проверки CI включают x64 Release-сборку Windows, тесты таймера, разбора и сериализации горячих клавиш, Settings, PowerManager, политики питания и расчёт SHA-256 для артефакта сборки.

Основной стек: C++17, нативный Win32 API, CMake и CTest.

## Проверка SHA-256 релиза

```powershell
(Get-FileHash .\Everon.exe -Algorithm SHA256).Hash.ToLower()
Get-Content .\Everon.exe.sha256
```

Значения SHA-256 должны совпадать.
