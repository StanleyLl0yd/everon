# История изменений

[![en](https://img.shields.io/badge/lang-en-red.svg)](CHANGELOG.md)
[![ru](https://img.shields.io/badge/lang-ru-blue.svg)](CHANGELOG.ru.md)

Здесь перечислены заметные изменения Everon.

---

## 2.6.0 — 2026-08-26

### Изменено

- Обновлён нативный диалог настроек: увеличена ширина, используется Segoe UI, удалено динамическое перемещение элементов управления.
- Упрощена настройка глобальной горячей клавиши: `Нет` отключает её, выбор сочетания включает.
- Поля интервала становятся неактивными, когда синтетическое нажатие клавиши выключено.
- Один клик по иконке в трее теперь открывает настройки; добавлена активация иконки с клавиатуры.
- Для отключённого состояния добавлена визуально приглушённая иконка в трее.
- Окно «О программе» сокращено до версии, назначения, автора, лицензии и ссылки на GitHub.

## 2.5.1 — 26.08.2026

### Исправлено

- При смене языка больше не теряются ещё не сохранённые настройки нажатия клавиши и глобальной горячей клавиши.
- Чтение строк из реестра защищено от некорректных значений без завершающего нулевого символа.
- Для определения пути EXE в автозапуске устранено ограничение `MAX_PATH`.

### Безопасность и надёжность

- В manifest явно задан запуск с обычными правами: `asInvoker`, `uiAccess=false`.
- Включены дополнительные защиты MSVC: SDL, Control Flow Guard и CET compatibility.
- Добавлены регрессионные тесты HotkeyManager и более строгая проверка сохранённых горячих клавиш.
- Публикация GitHub Releases переведена на теги; уже опубликованные assets больше не перезаписываются.

## 2.5 — 26.08.2026

### Изменено

- Во всех частях приложения и метаданных EXE лицензия приведена к PolyForm Noncommercial License 1.0.0.
- Версия приложения обновлена до 2.5.
- Немного расширена и переразложена форма настроек, чтобы длинные локализованные подписи помещались свободнее.
- Описание продукта в метаданных исправлено: Everon корректно описывается как утилита, поддерживающая компьютер в активном состоянии.
- README на английском и русском дополнены инструкциями по сборке, тестированию, совместимости и portable-использованию.

### Добавлено

- Воспроизводимая сборка Windows через CMake.
- GitHub Actions для сборки x64 Release.
- Регрессионные тесты `TimerMode` через CTest.
- Автоматический расчёт SHA-256 для артефактов CI.

### Обслуживание

- Из репозитория удалён генерируемый кэш редактора ресурсов Visual Studio `src/app.aps`.

## 2.4 — 10.02.2026

- Работа из системного трея и предотвращение автоматического сна.
- Опциональное удержание дисплея включённым.
- Опциональная отправка F15/F16/F17.
- Режимы таймера: бесконечно, на заданное время и до указанного времени.
- Глобальная горячая клавиша включения/выключения.
- Опциональный автозапуск с Windows.
- Шесть языков интерфейса: английский, русский, французский, немецкий, итальянский и испанский.
- Улучшена надёжность восстановления иконки в трее, таймеров, переходов DST и обработки ошибок WinAPI.
