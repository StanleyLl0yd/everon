# История изменений

[English](CHANGELOG.md) | [Русский](CHANGELOG.ru.md)

Здесь перечислены заметные изменения Everon.

## 2.5 — 26.08.2026

### Изменено

- Во всех частях приложения и метаданных EXE лицензия приведена к PolyForm Noncommercial License 1.0.0.
- Версия приложения обновлена до 2.5.
- Немного расширена и переразложена форма настроек, чтобы длинные локализованные подписи помещались свободнее.
- Описание продукта в метаданных исправлено: Everon корректно описывается как утилита, поддерживающая компьютер в активном состоянии.
- README на английском и русском дополнены инструкциями по сборке, тестированию, совместимости и portable-использованию.

### Добавлено

- Воспроизводимая сборка Windows через CMake.
- GitHub Actions для сборки x64 Release.
- Регрессионные тесты `TimerMode` через CTest.
- Автоматический расчёт SHA-256 для артефактов CI.

### Обслуживание

- Из репозитория удалён генерируемый кэш редактора ресурсов Visual Studio `src/app.aps`.

## 2.4 — 10.02.2026

- Работа из системного трея и предотвращение автоматического сна.
- Опциональное удержание дисплея включённым.
- Опциональная отправка F15/F16/F17.
- Режимы таймера: бесконечно, на заданное время и до указанного времени.
- Глобальная горячая клавиша включения/выключения.
- Опциональный автозапуск с Windows.
- Шесть языков интерфейса: английский, русский, французский, немецкий, итальянский и испанский.
- Улучшена надёжность восстановления иконки в трее, таймеров, переходов DST и обработки ошибок WinAPI.
