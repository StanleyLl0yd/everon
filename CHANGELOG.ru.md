# История изменений

Здесь перечислены заметные изменения Everon.

---

## 2.8.0 — 2026-08-27

### Добавлено

- Добавлено периодическое обновление статуса в трее, чтобы информация активного таймера оставалась актуальной во время работы Everon.
- В меню трея добавлена строка состояния и отметки активных быстрых таймеров по длительности.
- Добавлены отдельные нативные диалоги `Другое...` для произвольной длительности и `До времени...`.
- Добавлены настройки поведения от батареи: учёт режима экономии заряда Windows и возможность отключать удержание дисплея включённым при работе от батареи.
- Добавлена явная обработка смены источника питания и выхода из сна с немедленной перепроверкой таймера и режима удержания системы активной.
- Добавлены регрессионные тесты политики питания и расширены тесты Settings.

### Изменено

- Для произвольного быстрого таймера и режима «До времени» больше не требуется открывать полный диалог настроек.
- Синтетические F15/F16/F17 временно не отправляются, когда политика Battery Saver приостанавливает удержание системы активной.
- Настройки батареи добавлены с сохранением прежнего поведения по умолчанию для обновляющихся пользователей.

### Безопасность и обслуживание

- GitHub Actions закреплены на неизменяемых commit SHA и актуальных версиях Actions на Node 24.
- Сборка/тестирование релиза и публикация разделены на отдельные jobs с минимально необходимыми правами.
- Ручной релиз теперь собирает точный commit запуска workflow через `github.sha`.
- Добавлена защита release-тегов `v*` и расширено регрессионное покрытие Settings и логики питания.

## 2.7.0 — 2026-08-26

### Добавлено

- Добавлены быстрые таймеры из меню в трее на 15 минут, 30 минут, 1 час и 2 часа.
- Добавлена локализованная пометка «Завтра», если выбранное время в режиме «До времени» относится к следующему дню.
- Добавлены автоматические повторные попытки и однократное предупреждение, если Windows временно не принимает запрошенный режим питания.

### Изменено

- Таймер длительности теперь использует монотонные часы, пока Everon работает, поэтому изменение системного времени не меняет активную длительность. Для восстановления после перезапуска по-прежнему используется сохранённый UTC-дедлайн.
- Внутреннее состояние режима питания теперь меняется только после успешного `SetThreadExecutionState`.
- Расширены регрессионные тесты таймера: монотонное время, восстановление после перезапуска и определение следующего дня.
- Удалены устаревшие строки локализации, которые больше не используются текущим интерфейсом.

## 2.6.1 — 2026-08-26

### Изменено

- Обычное сообщение «О программе» заменено компактным нативным Win32-диалогом.
- Ссылка на репозиторий GitHub в окне «О программе» теперь кликабельная и доступна с клавиатуры через `SysLink`; она открывается в браузере по умолчанию.

## 2.6.0 — 2026-08-26

### Изменено

- Обновлён нативный диалог настроек: увеличена ширина, используется Segoe UI, удалено динамическое перемещение элементов управления.
- Упрощена настройка глобальной горячей клавиши: `Нет` отключает её, выбор сочетания включает.
- Поля интервала становятся неактивными, когда синтетическое нажатие клавиши выключено.
- Один клик по иконке в трее теперь открывает настройки; добавлена активация иконки с клавиатуры.
- Для отключённого состояния добавлена визуально приглушённая иконка в трее.
- Окно «О программе» сокращено до версии, назначения, автора, лицензии и ссылки на GitHub.

## 2.5.1 — 26.08.2026

### Исправлено

- При смене языка больше не теряются ещё не сохранённые настройки нажатия клавиши и глобальной горячей клавиши.
- Чтение строк из реестра защищено от некорректных значений без завершающего нулевого символа.
- Для определения пути EXE в автозапуске устранено ограничение `MAX_PATH`.

### Безопасность и надёжность

- В manifest явно задан запуск с обычными правами: `asInvoker`, `uiAccess=false`.
- Включены дополнительные защиты MSVC: SDL, Control Flow Guard и CET compatibility.
- Добавлены регрессионные тесты HotkeyManager и более строгая проверка сохранённых горячих клавиш.
- Публикация GitHub Releases переведена на теги; уже опубликованные assets больше не перезаписываются.

## 2.5 — 26.08.2026

### Изменено

- Во всех частях приложения и метаданных EXE лицензия приведена к PolyForm Noncommercial License 1.0.0.
- Версия приложения обновлена до 2.5.
- Немного расширена и переразложена форма настроек, чтобы длинные локализованные подписи помещались свободнее.
- Описание продукта в метаданных исправлено: Everon корректно описывается как утилита, поддерживающая компьютер в активном состоянии.
- README на английском и русском дополнены инструкциями по сборке, тестированию, совместимости и portable-использованию.

### Добавлено

- Воспроизводимая сборка Windows через CMake.
- GitHub Actions для сборки x64 Release.
- Регрессионные тесты `TimerMode` через CTest.
- Автоматический расчёт SHA-256 для артефактов CI.

### Обслуживание

- Из репозитория удалён генерируемый кэш редактора ресурсов Visual Studio `src/app.aps` из version control.

## 2.4 — 10.02.2026

- Работа из системного трея и предотвращение автоматического сна.
- Опциональное удержание дисплея включённым.
- Опциональная отправка F15/F16/F17.
- Режимы таймера: бесконечно, на заданное время и до указанного времени.
- Глобальная горячая клавиша включения/выключения.
- Опциональный автозапуск с Windows.
- Шесть языков интерфейса: английский, русский, французский, немецкий, итальянский и испанский.
- Улучшена надёжность восстановления иконки в трее, таймеров, переходов DST и обработки ошибок WinAPI.
